# LaunchGuard AI

Real-time website testing, security configuration inspection, performance & SEO analysis, broken link verification, and AI-guided launch readiness reports.

### Custom Palette
- **Cream (`#F2E8DA`) ~65–70%**: Main body background, warm card surfaces, borders (`#D9C7B2`, `#E4D6C4`), inputs.
- **Espresso Brown (`#3B2418`) ~20–25%**: Sidebar navigation, card headers, table header banners, dark buttons.
- **Baby Blue (`#8EC5FF`) ~10%**: Interactive action buttons, active tabs, progress bars, badge highlights.

## Run Locally

**Prerequisites:** Node.js (v18+)

1. Install dependencies:
   ```bash
   npm install
   ```
2. (Optional) Set your `GEMINI_API_KEY` in `.env` or `.env.local` for AI Analyst reviews.
3. Start the application:
   ```bash
   npm run dev
   ```
4. Open [http://localhost:3000](http://localhost:3000) in your browser.
